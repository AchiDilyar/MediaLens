原生 macOS 媒体信息查看器，拖入视频、音频或图片即可检查媒体参数。

- 紧凑概览、属性搜索、视频 / 图片缩略图。
- 文件预览支持双击打开、拖出复制与快速查看。
- 访达服务“通过MediaLens查看媒体信息”。
- 复制报告、导出文本与 JSON。
- 内置独立 ffprobe，附对应源码与 LGPL 许可。
- 一份通用 DMG，包含 Intel x86_64 和 Apple Silicon arm64。

**下载**：`MediaLens.dmg`；校验文件：`MediaLens.dmg.sha256`。

**安装**：打开 DMG，将 MediaLens 拖入 Applications，再打开应用。支持 macOS 14 或更新版本。

**签名状态**：默认构建使用 ad-hoc 签名，尚未经过 Developer ID 签名与 Apple 公证。首次下载可能受到 Gatekeeper 拦截；正式公证发行前请保留此说明。

图标预览由系统 Quick Look 提供；不支持缩略图的格式会显示系统文件图标。媒体字段以文件实际提供的信息为准。
